================================================================
OSRS BOSS HELPER - RUNELITE PLUGIN SETUP GUIDE
================================================================

Goal: get a working RuneLite plugin that syncs your bank to the
boss-helper web app running on localhost:3000.

------------------------------------------------------------------
NOTE (updated): The plugin is now a COMPLETE, working project at
  C:\Users\enune\Desktop\osrs-boss-sync-plugin
  (GitHub: ENiceApps/osrs-boss-sync-plugin)
That repo is the single source of truth for the plugin. The phases
below are the original from-scratch build log; to just RUN it, open
that repo and run `.\gradlew.bat run` (see project memory for the
Jagex-auth recipe). The plugin source files that used to be vendored
here under runelite-plugin/ have been removed to avoid two copies
drifting apart — edit the source in the osrs-boss-sync-plugin repo.
------------------------------------------------------------------

This guide assumes you've never built a RuneLite plugin before
and you're on Windows. Each phase has a clear stop-and-verify
point - do NOT try to do all five in one sitting. If you hit
any error at any phase, capture the exact text and ask for help.


================================================================
PHASE 0  -  Verify the web side works (~3 minutes)
================================================================

Before touching any Java, prove the endpoint already works by
faking the plugin with curl. If this works, you know the plugin
only has to do "send same payload" -- much easier to debug later.

STEP 1. Make sure the dev server is running.
  Open PowerShell and run:

      cd "C:\Users\enune\Desktop\Claude Code Projects\osrs-boss-helper-transfer\osrs-boss-helper"
      npm.cmd run dev

  Leave it running. You should see "Ready in ..." on
  http://localhost:3000.

STEP 2. Open the boss page in your browser:

      http://localhost:3000/boss/vorkath

  The banner at the top should say "Sample bank in use."

  >>> If you see a "Runtime Error" / Turbopack error instead,
      hard-refresh the tab (Ctrl + Shift + R). The browser
      probably cached stale chunks from before a hot reload.

STEP 3. Fake the plugin from another PowerShell window:

      curl.exe -X POST http://localhost:3000/api/bank -H "Content-Type: application/json" -d "{\"items\":[{\"id\":21012,\"qty\":1},{\"id\":9243,\"qty\":200},{\"id\":27235,\"qty\":1},{\"id\":22109,\"qty\":1},{\"id\":12018,\"qty\":1},{\"id\":27238,\"qty\":1},{\"id\":27241,\"qty\":1},{\"id\":26235,\"qty\":1},{\"id\":13237,\"qty\":1},{\"id\":28310,\"qty\":1},{\"id\":22002,\"qty\":1}],\"skills\":{\"attack\":99,\"strength\":99,\"defence\":99,\"ranged\":99,\"magic\":99,\"hitpoints\":99,\"prayer\":99},\"gp\":50000000,\"playerName\":\"TestPlayer\"}"

STEP 4. Within 5 seconds, the page banner should flip to:

      "* Live bank * TestPlayer * synced 0s ago"

  >>> If it flipped: web side is good. Continue to Phase 1.
  >>> If it didn't: stop here and ask for help.


================================================================
PHASE 1  -  Install Java tooling (~15 minutes)
================================================================

You need two things: a JDK (Java compiler/runtime) and an IDE
(IntelliJ IDEA Community Edition).

----------------------------------------------------------------
STEP 1a. Install Adoptium Temurin JDK 17 (LTS)
----------------------------------------------------------------

  Download from:
      https://adoptium.net/temurin/releases/?version=17

  Pick the Windows x64 MSI installer for JDK 17 (LTS).

  Run the MSI. IMPORTANT: in the installer options,
  CHECK both these boxes:
      [x] Set JAVA_HOME variable
      [x] Add to PATH

  Verify by opening a NEW PowerShell window (must be opened
  after the install so PATH gets refreshed):

      java -version

  Expected output:
      openjdk version "17.0.x" ...
      OpenJDK Runtime Environment Temurin-17 ...

  >>> If you see "command not recognized", reboot and try
      again. The PATH update sometimes needs a restart.

----------------------------------------------------------------
STEP 1b. Install IntelliJ IDEA Community Edition (free)
----------------------------------------------------------------

  Download from:
      https://www.jetbrains.com/idea/download/?section=windows

  Pick "Community Edition" -> Download -> install with defaults.

  First-launch wizard: skip import, pick a UI theme, decline
  the optional plugins. Land on the welcome screen.


================================================================
PHASE 2  -  Get the RuneLite example plugin project (~5 minutes)
================================================================

The "example-plugin" repo is a ready-to-run Gradle project that
knows how to launch RuneLite with your plugin pre-loaded. We
fork from it instead of writing the build setup ourselves.

STEP 1. Clone it (in PowerShell):

      cd C:\Users\enune\Desktop
      git clone https://github.com/runelite/example-plugin.git osrs-boss-sync-plugin
      cd osrs-boss-sync-plugin

STEP 2. Open it in IntelliJ:
  File -> Open -> pick the folder:
      C:\Users\enune\Desktop\osrs-boss-sync-plugin
  Click "Trust Project" when prompted.

  IntelliJ will spend ~2 minutes downloading Gradle dependencies.
  Wait for the bottom status bar to STOP showing "Indexing...".

STEP 3. While it's loading, browse the left panel to:
      src/main/java/com/example/ExamplePlugin.java
  Open it. You'll see a tiny example plugin - we're about to
  replace this.


================================================================
PHASE 3  -  Drop in our plugin code (~10 minutes)
================================================================

STEP 1. Copy our plugin source files into the example-plugin
project. Open a fresh PowerShell window and run:

      $src = "C:\Users\enune\Desktop\Claude Code Projects\osrs-boss-helper-transfer\osrs-boss-helper\runelite-plugin\src\main\java\com\osrsbosshelper"
      $dst = "C:\Users\enune\Desktop\osrs-boss-sync-plugin\src\main\java\com\example"
      Copy-Item "$src\BankSyncPlugin.java" "$dst\BankSyncPlugin.java"
      Copy-Item "$src\BankSyncConfig.java" "$dst\BankSyncConfig.java"

STEP 2. Delete the old example plugin file.
  In IntelliJ's left panel:
      right-click ExamplePlugin.java -> Delete -> "Safe Delete" -> OK.

STEP 3. Fix the package declarations.
  Open BOTH new files in IntelliJ. At the top of each, change:

      package com.osrsbosshelper;

  to:

      package com.example;

  (This matches the example project's package. You can rename
  the whole package later if you want - that's a refactor for
  another day.)

STEP 4. Update the plugin manifest.
  Use IntelliJ's file search (Ctrl + Shift + N) to find:
      runelite-plugin.properties

  Change the mainClass line to:
      mainClass=com.example.BankSyncPlugin

  Change the name to:
      name=OSRS Boss Helper Sync

STEP 5. Watch IntelliJ for red squiggles.
  Most imports should resolve automatically once Gradle finishes.
  If anything stays red, hover over it - IntelliJ usually
  offers "Import class" as a quick-fix (Alt + Enter).

STEP 6. Sanity build.
  View -> Tool Windows -> Gradle -> expand "example-plugin"
  -> Tasks -> build -> double-click "build".

  Watch the output panel. A successful build ends with:
      BUILD SUCCESSFUL

  >>> If you see "BUILD FAILED" with errors, copy the exact
      output and ask for help.


================================================================
PHASE 4  -  Launch RuneLite with the plugin loaded (~5 minutes)
================================================================

The example-plugin project has a Gradle task that boots RuneLite
in developer mode with your plugin already loaded. No sideloading
needed.

STEP 1. In IntelliJ's Gradle panel:
      example-plugin -> Tasks -> application -> double-click "runClient"

  (If you don't see runClient, try "run" instead.)

STEP 2. First launch downloads RuneLite (~50 MB) and the OSRS
cache (~150 MB). Takes 30 seconds to 2 minutes depending on
your connection.

STEP 3. The RuneLite window opens. Log in to your OSRS account.

STEP 4. Enable the plugin in RuneLite:
  - Click the wrench icon on the right side ("Configuration")
  - In the search box, type: OSRS Boss Helper Sync
  - Toggle it ON.

STEP 5. Open the plugin's config by clicking its name. You
should see:
      Endpoint URL:           http://localhost:3000/api/bank
      Sync on bank change:    [x]
      Min sync interval (ms): 2000

  These defaults match the dev server you started in Phase 0.


================================================================
PHASE 5  -  Verify it works (~2 minutes)
================================================================

STEP 1. In-game: open ANY bank (the bank in Lumbridge, the
bank at Edgeville, anywhere). The plugin reads bank data
through RuneLite's API, which is only populated AFTER you've
opened the bank at least once per session.

STEP 2. In RuneLite: open the developer logs.
  View -> Tool Windows -> "Logs"
  (In dev mode this may be labeled "Developer Tools")

  Look for one of:
      OK   "BankSyncPlugin: posted N items"
                  -> plugin pushed your bank successfully

      FAIL "Bank sync POST failed: ..."
                  -> network problem; dev server probably not running

  If you see something else, copy the exact log line.

STEP 3. In your browser: refresh
  http://localhost:3000/boss/vorkath

  The banner should flip from "Sample bank in use" to:
      "* Live bank * YourRSN * synced Xs ago"

STEP 4. Try changing your bank in-game - deposit something,
withdraw something. Within ~2 seconds (the throttle), the page
should re-render with a fresh upgrade path reflecting the
change.

When this works, you're done. The plugin is live.
